# План отслеживания событий и разметки пикселей (Event Tracking Plan)

Поскольку наш сайт является одностраничным приложением (Vite Singlefile SPA), стандартный учет просмотров страниц (Pageviews) не дает полной картины поведения пользователей. Мы настраиваем событийную аналитику (Event-based Analytics) в Яндекс Метрике и Google Analytics 4.

---

## 1. Спецификация событий на сайте (Event Schema)

Ниже представлена таблица разметки JavaScript-событий для кнопок и форм на нашем лендинге:

| Название события в коде | Триггер (Действие пользователя) | Цель в Яндекс Метрике | Назначение и оптимизация рекламы |
| :--- | :--- | :--- | :--- |
| `click_hero_catalog` | Клик по кнопке «Смотреть каталог» в Hero-блоке | `HERO_CATALOG` | Анализ интереса к ассортименту |
| `filter_category_change` | Клик по кнопке фильтра категорий (Face, Body, SPF, Makeup) | `FILTER_CHANGE` | Сегментация интереса аудитории |
| `search_query_input` | Ввод символов в поисковую строку каталога | `SEARCH_INPUT` | Анализ поискового намерения на сайте |
| `click_product_card` | Клик по карточке товара для открытия модального окна (PDP) | `PRODUCT_VIEW` | Главная микро-конверсия (Интерес к продукту) |
| `click_pdp_order_tg` | Клик по кнопке «Купить в Telegram» внутри PDP Modal | `ORDER_TELEGRAM` | **Макро-конверсия (Попытка заказа в TG)** |
| `click_article_card` | Клик по статье Бьюти-гида для открытия модального окна | `ARTICLE_VIEW` | Оценка вовлеченности в контент |
| `submit_contact_form` | Успешная отправка формы обратной связи в блоке поддержки | `CONTACT_SUBMIT` | **Макро-конверсия (Заявка на подбор косметики)** |
| `submit_footer_newsletter`| Успешная отправка email в форме подписки в футере | `NEWSLETTER_SUBMIT`| Конверсия в базу рассылки |

## 2. Скрипт интеграции Яндекс Метрики (JS Code Snippet)
Для отслеживания кликов по ссылкам мессенджеров, в код кнопок `App.tsx` встроены вызовы JavaScript API Яндекс Метрики:

```javascript
// Пример вызова события при клике на покупку в Telegram
const handleTelegramClick = (productName) => {
  if (typeof ym !== 'undefined') {
    ym(99999999, 'reachGoal', 'ORDER_TELEGRAM', { product: productName });
  }
};
```

Такая разметка позволяет запускать в Яндекс Директе и ВКонтакте рекламные кампании с оплатой за целевое действие (например, платить только за пользователей, которые реально кликнули «Купить в Telegram» или отправили форму подбора ухода).
