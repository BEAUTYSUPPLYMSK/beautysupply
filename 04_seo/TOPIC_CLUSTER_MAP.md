# Карта тематических кластеров (Topic Cluster Map)

Метод тематических кластеров подразумевает создание одной большой опорной страницы (Pillar Page) и нескольких детальных вспомогательных страниц (Cluster Pages), которые ссылаются друг на друга. Это создает идеальную структуру для поисковых роботов.
