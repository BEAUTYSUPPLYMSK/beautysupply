# Архитектура бьюти-сайта (Site Architecture)

Сайт `beautysupply.shop` спроектирован как высокопроизводительное одностраничное приложение (SPA - Single Page Application) с бесшовными интерактивными переходами, контекстными всплывающими окнами (модальными окнами) и якорной навигацией.

## 2. Логика интерактивного взаимодействия (Interactivity Matrix)

1. **Якорное скольжение (Anchor Scroll)**: Клик по любому пункту навигационного меню в шапке сайта плавно перемещает пользователя к соответствующему блоку страницы благодаря CSS-правилу `scroll-behavior: smooth`. На мобильных устройствах клик также автоматически закрывает шторку меню.
2. **Фильтрация в реальном времени (Category Filters)**: Клик по категории каталога моментально скрывает неподходящие товары с помощью обновления стейта React. Смена категорий происходит без перезагрузки страницы за 0 миллисекунд.
3. **Живой поиск (Live Search)**: Ввод текста в поисковую строку фильтрует товары одновременно по названию, бренду и описанию. При вводе нерелевантного запроса сайт показывает красивую заглушку с предложением сбросить фильтры.
4. **Интерактивные модальные окна (Modals)**: 
   - *Для товаров*: Клик на карточку товара открывает подробную страницу продукта (PDP), блокируя прокрутку основного экрана для концентрации внимания покупателя.
   - *Для статей*: Клик по карточке Бьюти-гида открывает всплывающее окно с полным текстом экспертного материала.
5. **Генератор заказов (Messenger Order Generator)**: Клик по кнопкам заказа в карточке товара генерирует уникальную API-ссылку с предзаполненным текстом заказа и открывает мессенджер пользователя (Telegram).
6. **Уведомления на сайте (Toast Notifications)**: Любое важное действие на сайте (отправка формы, подписка на рассылку) сопровождается красивым всплывающим снизу информационным окном, которое исчезает через 5 секунд.
