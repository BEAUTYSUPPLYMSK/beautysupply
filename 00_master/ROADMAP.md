# Дорожная карта реализации проекта (Roadmap)

В данном документе зафиксирован пошаговый 10-этапный план построения, комплаенса, запуска, масштабирования и оптимизации бьюти-бизнеса Beauty Supply.

---

## 1. Этапы реализации

### Шаг 1: Глубокий аудит и планирование архитектуры [ВЫПОЛНЕНО]
- Аудит файлов репозитория, анализ дизайн-макета `web-design-beta-version.png`.
- Исправление структуры директорий (перенос React-кода в папку `src/`).
- Тестовая компиляция проекта.

### Шаг 2: Исследование рынка и позиционирование [ВЫПОЛНЕНО]
- Оценка объемов рынка бьюти-сферы РФ в 2025–2026 гг.
- Анализ конкурентов (Золотое Яблоко, Рив Гош, серые байеры).
- Описание уникального торгового предложения (USP).
- Создание файлов в директории `01_market/`.

### Шаг 3: Юридический аудит и комплаенс-стратегия [ВЫПОЛНЕНО]
- Анализ ТР ТС 009/2011, правил маркировки «Честный Знак» и закона 54-ФЗ.
- Разработка правил возврата и требований к русскоязычному стикеру.
- Создание файлов в директории `02_legal/`.

### Шаг 4: Проектирование товарной матрицы [ВЫПОЛНЕНО]
- Описание 12 SKU в наличии и 40+ виртуальных SKU под предзаказ.
- Расчет маржинальности, себестоимости и цен реализации.
- Маппинг товаров по проблемам кожи (Concern-Fit) и сезонности спроса.
- Дополнение файлов в директории `01_market/`.

### Шаг 5: Архитектура каналов продаж (Omnichannel Funnel) [ВЫПОЛНЕНО]
- Разработка регламентов ведения Telegram, VK, YouTube, Rutube.
- Построение схемы движения пользователя (Funnel Map).
- Создание файлов в директории `05_channel/`.

### Шаг 6: SEO-архитектура и Бьюти-гид [ВЫПОЛНЕНО]
- Сбор семантического ядра и группировка ключевых запросов.
- Описание структуры тематических кластеров (Pillar-Cluster) и перелинковки.
- Разработка SEO-рекомендаций для карточек товаров (PDP).
- Создание файлов в директории `04_seo/`.

### Шаг 7: Верстка визуального стиля и структуры сайта [ВЫПОЛНЕНО]
- Подключение шрифтов (Playfair Display, Inter) и палитры из дизайн-макета.
- Разработка и верстка 12 блоков главной страницы лендинга в `src/App.tsx`.
- Настройка компиляции Vite Singlefile.

### Шаг 8: Разработка интерактивного функционала и UX [ВЫПОЛНЕНО]
- Добавление фильтрации по категориям, живого поиска, всплывающих тостов.
- Реализация всплывающего окна карточки товара (PDP Modal) с детальным составом.
- Интеграция 1-click генератора шаблонов заказов для Telegram.
- Создание файлов документации в директории `03_ux/`.

### Шаг 9: Сборка полной файловой структуры базы знаний [ВЫПОЛНЕНО]
- Развертывание всех оставшихся папок базы знаний (`00_master`, `06_operations`, `07_analytics`, `08_strategy`, `09_sources`) и наполнение регламентированными Markdown файлами.

### Шаг 10: Финальная проверка, деплой и привязка домена [ВЫПОЛНЯЕТСЯ]
- Инструкция по заливке единого HTML на Porkbun / GitHub Pages (`DEPLOY_GUIDE.md`).
- Финальный аудит готовности к масштабированию.
- В репозиторий добавлен готовый собранный артефакт `docs/index.html` для мгновенного деплоя на GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/docs`). Опциональный воркфлоу GitHub Actions описан в `DEPLOY_GUIDE.md`. Осталось включить Pages-деплой в настройках репозитория и, при желании, привязать домен `beautysupply.shop`.
