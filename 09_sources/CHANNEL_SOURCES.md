# Источники по SMM и маркетингу в мессенджерах (Channel Sources)

Руководства по оптимизации воронки продаж в социальных сетях, маркировке рекламы и автоматизации рассылок.

---

## Источники и Гайды

1. **Роскомнадзор — Единый Реестр Интернет-Рекламы (ЕРИР)**  
   - *Ссылка*: [https://erir.grfc.ru/](https://erir.grfc.ru/)  
   - *Описание*: Официальные правила маркировки блогов, получения уникальных erid-токенов через ОРД и сдачи отчетности по интеграциям.

2. **Telegram API — Чат-боты и линки заказов**  
   - *Ссылка*: [https://core.telegram.org/bots](https://core.telegram.org/bots)  
   - *Описание*: Документация по настройке глубоких ссылок (Deeplinks) и шаблонов сообщений с авто-заполнением для быстрого перевода клиентов с сайта в чат к менеджеру.

3. **ВКонтакте для бизнеса — Рекламный Кабинет**  
   - *Ссылка*: [https://vk.com/biz](https://vk.com/biz)  
   - *Описание*: Рекомендации по оптимизации таргетированных кампаний, настройки пикселей ретаргетинга и создания каруселей товаров.
