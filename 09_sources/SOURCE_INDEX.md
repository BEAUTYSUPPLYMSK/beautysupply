# Главный индекс источников (Source Index)

В данном документе собрана централизованная база проверенных, высокоинформативных первоисточников, законов, регулирующих документов и маркетинговых исследований, использованных при построении базы знаний Beauty Supply.

---

## 1. Категории источников

1. **Маркетинговые источники (`09_sources/MARKET_SOURCES.md`)**: Сбор данных по парфюмерно-косметическому рынку РФ на 2025–2026 гг., аналитика средних чеков и конкурентного ландшафта.
2. **Юридические источники (`09_sources/LEGAL_SOURCES.md`)**: Официальные федеральные законы РФ (54-ФЗ, ФЗ «О рекламе», Закон о защите прав потребителей), регламент ТР ТС 009/2011, постановления Правительства и инструкции ГИС МТ «Честный Знак».
3. **Источники по UX/UI (`09_sources/UX_SOURCES.md`)**: Стандарты проектирования веб-интерфейсов, адаптивность Mobile-First, руководства по доступности WCAG и спецификации Google Core Web Vitals.
4. **Источники по SEO (`09_sources/SEO_SOURCES.md`)**: Документация Google по алгоритмам E-E-A-T, валидаторы Schema.org, семантические инструменты.
5. **Источники по каналам продаж (`09_sources/CHANNEL_SOURCES.md`)**: Официальные гайды по маркировке рекламы и воронкам в мессенджерах.
6. **Операционные источники (`09_sources/OPERATIONS_SOURCES.md`)**: API курьерских служб (СДЭК) и документации платежных эквайрингов в РФ.
7. **Аналитические источники (`09_sources/ANALYTICS_SOURCES.md`)**: JS API Яндекс Метрики и Google Analytics 4.
