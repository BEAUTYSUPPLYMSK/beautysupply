# Источники по веб-аналитике и скриптам (Analytics Sources)

Техническая документация систем аналитики для отслеживания конверсий на Vite SPA сайтах.

---

## Документация API

1. **Яндекс Метрика — Техническое руководство разработчика (JS API)**  
   - *Ссылка*: [https://yandex.ru/support/metrika/objects/method-reference.html](https://yandex.ru/support/metrika/objects/method-reference.html)  
   - *Описание*: Инструкции по вызову функции `ym()` для отслеживания целей «reachGoal» при кликах по мессенджерам.

2. **Google Analytics 4 — Разметка событий и Gtag.js**  
   - *Ссылка*: [https://developers.google.com/analytics/devguides/collection/ga4](https://developers.google.com/analytics/devguides/collection/ga4)  
   - *Описание*: Руководство по интеграции глобального тега и отправке кастомных событий для оценки конверсий на одностраничных сайтах.
