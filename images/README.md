# Папка для загружаемых изображений

Сюда загружаются новые изображения товаров (фото и скриншоты с объявлений Avito и др.).

## Как загрузить через веб-интерфейс GitHub

1. Откройте эту папку в репозитории на GitHub.
2. Нажмите **Add file → Upload files**.
3. Перетащите изображения в окно и нажмите **Commit changes**.

Файлы окажутся здесь, в `images/`.
